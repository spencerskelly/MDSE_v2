# Real-Data Test Log

Purpose: index (DAT-002 applies: file names and one-line summaries only) of test runs against real engineering data that found issues. Keep the evidence file for later reference. The evidence file itself is held in private storage, not in this repository. Raw engineering data never goes into this repository.

Policy:
- A run with no issues does not need an entry.
- A run with issues gets one entry, and its evidence file is kept in private storage.
- Each entry names the evidence file so it can be requested later for upload or review.

## Entry format

| Date | Run | Source | Evidence file | Stored at | Issue summary | Status |
|---|---|---|---|---|---|---|

Field notes:
- **Run:** the phase and step, for example "Phase 1 EA import" or "Phase 2 BOM import".
- **Source:** the file name or identifier of the real source, not its contents.
- **Evidence file:** the file name of the evidence report.
- **Stored at:** the private location where the file is kept.
- **Issue summary:** one line describing the issue.
- **Status:** open, resolved, or deferred, with the date.
