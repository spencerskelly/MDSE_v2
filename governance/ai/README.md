# AI files

Instructions for AI tools working **inside an engineering vault**. Everything in this folder ships into the vault at `99_System/02_AI/` (see [../ARCHITECTURE.md](../ARCHITECTURE.md)).

| File | Purpose |
|---|---|
| [AI_INSTRUCTIONS.md](AI_INSTRUCTIONS.md) | How any AI tool creates and edits notes |
| [processes/AI-CR-01_Changelog_Review.md](processes/AI-CR-01_Changelog_Review.md) | Changelog review before an engineer reads an import's changes |

Adding a process: give it the next `AI-xx-nn` ID, write its file under `processes/`, add it to the table in AI_INSTRUCTIONS.md and MDSE_DEFINITION.md, and record a decision (AIP rules).

Instructions for AI agents working on **this repository** are in [/AGENTS.md](../../AGENTS.md).
