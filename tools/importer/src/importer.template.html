3Destination

Leave this alone to get a ZIP of a new vault. Or choose a folder to write into: an empty folder gets the whole vault; a folder that already holds a vault is only added to, and nothing is deleted.

No folder chosen: a ZIP will be built.

In an existing vault a note found by uid keeps your text, status and tags; only EA-owned keys, ## Source: EA and ## SysML v2 refresh. Part numbers that already have a BOM note are left as they are.

On Windows keep the path short: write to a folder such as C:\MDSE that OneDrive does not sync, or extract the ZIP to a short path (not Downloads). Windows refuses paths over 260 characters, and cloud sync or antivirus can interrupt writes to a synced folder.

Working…

    Update an existing vault from a BOM

    For a later BOM export. Choose the BOM in step 2 and the vault folder in step 3 (read & write), then scan. Nothing is written by the scan. You get the changes grouped by category. Additions (data the note lacks) are ticked for you; changes and removals are not. Tick or untick a whole category or single items. Only what the BOM wrote is compared and changed: in a note merged with its EA element, the ports, satisfy, connect and everything else from the model stay as they are. Notes whose BOM-written parts were edited after the last import are compared too: the BOM's value is offered back and every item for them is marked [edited since last import], because applying it replaces the edit. Notes with no import stamp are listed and left alone.

    Maintenance · Update vault configuration (no source needed)

    Choose a vault folder in step 3, then preview. Brings Bootstrap, the Workbench, Templater, Advanced Canvas, Obsidian Git, their governed settings, schemas, templates and AI instructions up to this importer's release. Your notes, attachments, plugin settings (data.json), README.md and anything else of yours are not touched; .gitignore, the plugin lists and .vault.yaml are merged, not replaced; nothing is deleted. Replaced templates and schemas are copied aside first.
