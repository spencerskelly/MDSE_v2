## Existing rule — verbatim

- **IMP-096** · Active · P1 — Structure, links, quantities and multiplicity are defined by the SysML v2 block and are not repeated in `## Source: EA`. Relationships SysML v2 has no form for, and identifying properties, stay in the YAML (`describes`, `eaType`, `uid`, `id`). `## Source: EA` holds only what is stored nowhere else: the note's EA GUID, the original name when the file name differs, alias, the kept tags, trigger and guard text, unresolved connectors and attachments. EA author, created date, type, stereotype and package are not written: the uid carries date and author, `eaType` carries type and stereotype, the folder carries the package.
