## Existing rule — verbatim

- **IMP-103** · Active · P1 — No folder or file name is cut to fit a path length; the 400-character path limit is handled after the import, not by the importer. A name is changed only for the safety rules of IMP-102 (the 150-character part limit, which is marked). The folder write retries a file up to six times with a growing delay on InvalidStateError, NoModificationAllowedError or NotReadableError (antivirus, cloud sync or the indexer touching a new file), and a write error names the browser error, its message and the path. (D-0036)
