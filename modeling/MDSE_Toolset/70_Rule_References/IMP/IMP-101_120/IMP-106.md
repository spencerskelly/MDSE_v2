## Existing rule — verbatim

- **IMP-106** · Active · P1 — A Port under a Part is the Part's block's own port and is not written as a usage of the Part. It merges, with one hop and never up the redefinition chain: (1) PDATA3 names a Port owned by the Part's block; (2) else the block has exactly one port with the same non-blank name; (3) else it is added to the block as a port of its own, flagged for review, and same-named ones on one block combine. A Part with no block defers the Port (`USAGE_WITHOUT_NOTE_OWNER`). A merged Port types an untyped block port from its PDATA1. (V1 W-114, W-130; D-0037)
