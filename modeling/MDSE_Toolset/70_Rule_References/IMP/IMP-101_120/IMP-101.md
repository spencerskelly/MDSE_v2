## Existing rule — verbatim

- **IMP-101** · Active · P1 — An EA Port becomes a port usage written `port name : [~]PortDef[mult]`. The type is the Port's PDATA1 (an EA interface Class, which is a port definition, IMP-104); the Classifier field is not the type. The multiplicity is the Multiplicity field, read as for parts; `~` is written when the object has an `isConjugated` tag with a true value (`true`, `yes`, `1` or EA's `-1`). A Port whose PDATA1 is not a port definition (a connector, a signal) is written without a type, the target is kept as a `- Port <name> is typed by [[…]]` line in Source, and the usage is flagged (`UNRESOLVED_PORT_TYPE:TARGET_IS_…`). (D-0033, D-0037)
