## Existing rule — verbatim

- **IMP-125** · Active · P1 — The importer can check a run before it writes: the full translation runs in memory and lists every flag, every deferred row and every problem, with a verdict. BLOCKED: the translation failed, a BOM error, or a file name the browser or Windows refuses. REVIEW: rows that would be skipped, conflicts with edits in the vault, BOM parts that differ from the vault, more than 10% of elements deferred, or over 50 BOM warnings. FLAGS: only flags. CLEAN: none. The check also says what becomes of every source row: standard; merged; imported but a value did not follow the standard (counted by code; nothing lost, something guessed); not in the model and may be lost (deferred or skipped by an error); text only; excluded by policy. It names the EA tables that are never read. (D-0041)
