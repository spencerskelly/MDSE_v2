## Existing rule — verbatim

- **IMP-124** · Active · P1 — A usage or definition name keeps what makes the EA name different. A voltage puts its V at the decimal point and takes its sign as a letter: `+3.3VDC` is `P3V3DC`, `-13.3VDC` is `N13V3DC`, `12.5V` is `12V5`, `12VDC` stays `12VDC`; an unsigned voltage that starts the name takes `P`, because an identifier cannot start with a digit (`3.3VDC` is `P3V3DC`, so it and `+3.3VDC` meet and the second is told apart by its type). Elsewhere a leading `+` is `plus`, a leading `-` is `minus`, a point between digits is `p`, `&` is `And`, `%` is `Pct`, `#` is `No`. A name that is only a number is named after its type (`wire1`, not `_1`). Where the identifier is not just a respelling of the EA name, the EA name is recorded in `## Source: EA`. Two usages with one name take the name of their type to tell them apart (`a`, then `a_IConductor`); only a repeat of the same type takes `_2`. Quoted SysML names are not used, because every Workbench reader would need to change. Definitions keep the full EA title as their name. (D-0041, D-0042; amends IMP-095, IMP-112)
