## Existing rule — verbatim

- **IMP-062** · Unreviewed · P1 — Merge by field ownership: EA owns source semantics, BOM owns versioned BOM evidence, MDSE owns canonical IDs, placement and derived projections, users own local annotations. Never silently overwrite manually edited semantic content. Reimport reconciles by (source system, source GUID, semantic role) to a stable target ID with a three-way comparison against the last-generated baseline, detecting source-changed, user-changed and concurrent change separately. Removal or relocation only through a tombstone/redirect plan. (REG-191, V2-37 (Phase 1 controls 5, 6)) *Note: Active; matches the user's merge rules in part.*
