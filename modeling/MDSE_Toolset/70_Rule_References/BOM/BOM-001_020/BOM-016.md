## Existing rule — verbatim

- **BOM-016** · Active · P2 — Each part number gets one `Object` (subtype part) note named `<PN>` (the part number alone, so the file name and the part number are the same value; the name is the H1 and a `- Name:` line in Source) under `BOM/Parts`: `part def P_<PN>` with `partNumber`, `revision` (CL1+CL2 as exported), `source`, `lifecycleState` attributes. The parent's block owns one part usage per line: whole-number counts with unit ea/piece become multiplicity; any other quantity is `quantity` plus the unit as written (case kept); line, pinned `childRevision`, reference designator, effectivity dates, SSC and notes are attributes. Drawing lines (name starts DWG) become a `Document` note under `BOM/Drawings` referenced from the parent and are not usages. Alternate-source rows attach to the line above. Parent note lists children in `hasPart`. (D-0032)
