## Existing rule — verbatim

- **BOM-017** · Active · P2 — The latest revision of a part number is the one it has as an assembly, or the one every parent pins when it is only a child. When there are several, or two revisions each have lines, the part number and the lines that use it are not imported and an error finding names the revisions (BOM-009, BOM-002). A parent pinning an older child revision gets a `flagConflict`; the child's body lists its older-revision users. Part numbers already noted in the vault are left as they are. Findings go to `99_System/11_Import/BOM Findings <date>.md`. EA to BOM matching by part number appearing in one EA element name, EA alias or PN tag is a report only. A part number that is already in the vault is kept; if the new file disagrees with it on any line (pinned revision, count or quantity, or a line that is new) the finding `EXISTING_DIFFERS` names the first lines that differ and nothing is rewritten. (D-0032, D-0040)
