## Existing rule — verbatim

- **BOO-007** · Active · P1 — Bootstrap runs after the person trusts the vault, about two seconds after layout. It checks each locked plugin's files against the lock, enables those that match, merges the lock's governed settings into their `data.json` (the person's other keys stay), enables required and switches off prohibited core plugins, and reports what it did in one notice. A plugin whose hash differs or whose file is missing stays off and is named. It never downloads. The command "Check and repair this vault" runs it again. (D-0032)
