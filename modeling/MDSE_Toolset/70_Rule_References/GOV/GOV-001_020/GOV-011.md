## Existing rule — verbatim

- **GOV-011** · Proposed · Standing — One coordinated release manifest pins compatible Base Vault, Importer, Bootstrap, Workbench and SysML rule/schema versions and hashes. Base owns default assets and managed settings; Bootstrap owns installation and upgrades; Workbench owns interactive model writes; Importer owns import reconciliation. No tool overwrites another tool's user-owned data. Author identity is provenance, not authentication; credentials stay in OS or service stores, never shared YAML. (REG-040, V2-58 (Shared Note and Release Contract))
