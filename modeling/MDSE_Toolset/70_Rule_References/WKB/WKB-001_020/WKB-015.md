## Existing rule — verbatim

- **WKB-015** · Active · P1 — The Ports tab checks before it previews: names are unique in the owner, a port or end is typed by a port definition, only items and attributes have a direction, a path must resolve through the owner's usages (inherited ones included), an interface connection joins ports, each port matches its end's type and conjugation, and a flow starts at an out (or inout) feature and ends at an in (or inout) one, with every `~` on the path reversing directions. Type or end mismatches that SysML allows (bound features of different types, both ports unconjugated) are shown as notes, not refusals. A member that has a body (properties, description) is not rewritten by the Ports tab. (D-0033)
