## Existing rule — verbatim

- **WKB-012** · Active · P1 — Relationship properties are written inside the relationship in SysML: a `doc` comment, `attribute name = value;` (or `attribute name { doc … }` when the value is not a plain number or simple text), usage modifiers `ordered` and `nonunique`, quantity and direction. The drop-down offers only the options that relationship has; a free attribute name is accepted only where the relationship allows it (not specializes or verifies). Renaming a usage is refused when its name is used elsewhere in the block. (D-0031)
